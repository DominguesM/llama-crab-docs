# Package Map

> Map the Rust and TypeScript packages that make up llama-crab.

`llama-crab` is the safe Rust layer over the bundled `llama.cpp` runtime. Use it when you want local GGUF inference directly from Rust code: text completion, chat, embeddings, structured output, tool-style prompts, reranking, FIM infill, speculative decoding, and multimodal vision/audio through `mtmd`.

The generated API reference is published at [`docs.rs/llama-crab`](https://docs.rs/llama-crab).

Use the package that matches your integration surface.

## Rust packages

The workspace is defined in the root `Cargo.toml` (`[workspace]`). Member crates are versioned together at `0.1.8` (workspace package version) and share the same edition, license and MSRV.

## Public API layers

Use the high-level API first:

- `Llama::load` owns backend, model, and context setup. It also accepts a
Hugging Face repo id (with `with_hf_filename`) to download a GGUF to the
HF cache before loading — see the
[llama-crab README](https://github.com/DominguesM/llama-crab/blob/main/crates/llama-crab/README.md).
- `LlamaParams` configures model path, context size, threads, GPU layers,
embedding mode, pooling, flash attention, FIM detection, HF options and
mobile presets.
- `create_completion`, `create_chat_completion`, `embed`, `rerank` and
`complete_infill` cover the common application flows.

Drop to lower-level modules when you need precise control:

- `model` for tokenization, detokenization, vocab and metadata.
- `context` and `batch` for manual decode/encode loops, plus
`seq_rm` / `seq_cp` / `seq_keep` / `seq_add` / `seq_div` for KV cache
management.
- `sampling` for sampler chains (17 strategies).
- `chat` for templates, roles, tool definitions, the streaming tool-call
parser and the Jinja2-subset renderer.
- `multimodal` for `mtmd` image/audio/projector handling (behind the
`mtmd` feature).
- `json_schema` for converting JSON Schema 2020-12 to GBNF.
- `speculative` for prompt-lookup n-gram speculative decoding and a
`DraftModel` trait for custom draft strategies.

## Minimum supported Rust version

The workspace pins `rust-version = "1.88"` (recorded in
`rust-toolchain.toml` and the workspace `[workspace.package]` block). CI and
release workflows use this channel.

Repository layout and build profiles are documented in
[Development](/contributing/development). Runnable examples live in the
separate `llama-crab-examples` repository.
