The plugin exposes Tauri v2 permissions for each IPC command. The build script (`build.rs`) enumerates the 14 commands and the Tauri permission generator emits a TOML file per command under `permissions/autogenerated/commands/`.

The default permission set (in `permissions/default.toml`) is:

```toml
[default]
description = "Allows local LLM inference through llama-crab."
permissions = [
  "allow-load-model",
  "allow-unload-model",
  "allow-list-models",
  "allow-retrieve-model",
  "allow-create-chat-completion",
  "allow-stream-chat-completion",
  "allow-create-completion",
  "allow-stream-completion",
  "allow-create-embedding",
  "allow-create-rerank",
  "allow-tokenize",
  "allow-tokenize-count",
  "allow-detokenize",
  "allow-cancel",
]
```

## Capability example

Grant every command to a window that owns inference (e.g. a chat window). The Tauri v2 capability file lives in `src-tauri/capabilities/`:

```json
{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "llama-crab-default",
  "description": "Allow the chat window to drive llama-crab inference.",
  "windows": ["main"],
  "permissions": [
    "llama-crab:default"
  ]
}
```

For a narrower read-only diagnostics view, list only the commands the window needs:

```json
{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "llama-crab-diagnostics",
  "description": "Read-only access for the diagnostics window.",
  "windows": ["diagnostics"],
  "permissions": [
    "llama-crab:allow-list-models",
    "llama-crab:allow-retrieve-model",
    "llama-crab:allow-cancel"
  ]
}
```

## Practical guidance

Use the default permission set for a local-first app that exposes all model operations. For a narrower UI, grant only the commands the window needs. For example, a read-only diagnostics view may need `allow-list-models` and `allow-retrieve-model` (plus `allow-cancel` for in-flight requests) but not the load, generate or embed commands.

Streaming chat requires both `allow-stream-chat-completion` (to start the stream) and `allow-cancel` (to abort it). The client cancels through `cancel` when the consumer drops the `AsyncIterable` early or aborts the `AbortSignal`, so always include `allow-cancel` in any capability that may invoke a streaming command.

Remember that permissions gate IPC access. They do not validate model paths, model provenance, prompt size, or resource usage. Apply those rules in your application layer.
