This section captures stable package contracts that are useful while
installing, configuring, or operating `llama-crab`.

Use the package that matches the integration surface in your application.
The workspace version is `0.1.6` and all packages are released in
lockstep.

## Rust crates

| Crate | Version | Role |
| --- | --- | --- |
| `llama-crab` | 0.1.6 | Safe high-level Rust API for model loading, completion, chat, embeddings, multimodal helpers, sampling, and structured output. |
| `llama-crab-sys` | 0.1.5 (workspace dep) | Low-level FFI and native build crate for llama.cpp, GGML, GGUF, and mtmd bindings. |
| `llama-crab-server` | 0.1.6 | HTTP server exposing local model inference through OpenAI-compatible routes and extras. |
| `tauri-plugin-llama-crab` | 0.1.6 | Tauri v2 command plugin that wraps local model state for desktop applications. |

The `llama-crab` and `llama-crab-sys` versions are out of step in the
workspace manifest (`Cargo.toml` pins `llama-crab-sys` at `0.1.5` from
the `0.1.5` line); the high-level API surface is unchanged between the
two and downstream consumers can pin `llama-crab = "0.1.6"` without
manual coordination of the FFI version.

## TypeScript packages

| Package | Version | Role |
| --- | --- | --- |
| `@llama-crab/core` | 0.1.6 | Shared TypeScript contracts, request mappers, and error classes. |
| `@llama-crab/tauri` | 0.1.6 | Tauri adapter that uses the plugin commands from frontend code. |

Both packages ship `dist/index.cjs` (CJS), `dist/index.js` (ESM), and
`dist/index.d.ts` (types). `sideEffects: false` and `types` are pinned in
the package manifest. The Tauri package depends on `@llama-crab/core` at
the same version and rebuilds it before its own `build`/`typecheck`/
`test` scripts run.
