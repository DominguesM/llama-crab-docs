Runnable examples live in the separate
[`llama-crab-examples`](https://github.com/DominguesM/llama-crab-examples)
repository. Clone it when you want executable examples that depend on
the published crates and npm packages.

The wrapper assumes the workspace `llama-crab` is at version `0.1.6` and
runs each binary in release mode.

These examples use a small instruct GGUF by default:
`models/qwen2.5-0.5b-instruct-q4_k_m.gguf`.

## Quickstart

```bash [Terminal]
./run.sh quickstart
```

Shows the broadest first-run path: load a model, tokenize a prompt,
generate a text completion, run one chat completion, and try
fill-in-the-middle.

## Simple completion

```bash [Terminal]
./run.sh simple
```

Runs a minimal one-shot completion with `Llama::load` and
`create_completion`. Direct form:

```bash [Terminal]
cargo run --release --bin simple -- models/qwen2.5-0.5b-instruct-q4_k_m.gguf "Once upon a time"
```

## Streaming

```bash [Terminal]
./run.sh streaming
```

Uses `create_completion_stream` (added in 0.1.4) and writes each chunk
to stdout as it arrives. The high-level API returns
`CompletionChunk` and lets the caller drive iteration. Use this as the
starting point for terminal UIs or HTTP streaming adapters.

## One-shot chat

```bash [Terminal]
./run.sh chat
```

Builds a short `Vec<ChatMessage>`, renders it with
`BuiltinTemplate::ChatMl`, and prints the assistant response. The chat
helper supports the `Role::Tool` variant and the
`ChatMessage::tool_result` / `with_tool_call` helpers in 0.1.6.

## Stateful chat

```bash [Terminal]
./run.sh stateful_chat
```

Starts an interactive REPL. The example keeps conversation history in
memory and supports:

- `/clear` to reset the history.
- `/save` to print the conversation as JSON.
- `/exit` to quit.

## Speculative decoding demo

```bash [Terminal]
./run.sh speculative
```

Demonstrates prompt lookup drafting with `PromptLookupDecoding`. It is a
compact API demonstration, not a benchmark harness.
